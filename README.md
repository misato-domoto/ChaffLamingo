# ChaffLamingo

座席レイアウトやメンバーを登録し、ランダムに座席を決めるサービス

## 技術スタック

- **言語**: TypeScript
- **フレームワーク**: Next.js
- **スタイリング**: Tailwind CSS
- **パッケージ管理**: bun
- **開発環境**: Dev Container

### 環境構築

1.VScodeからWSLに接続する。

2.任意のディレクトリで`git clone <https://github.com/misato-domoto/ChaffLamingo.git>`

3.`Devcontainer`でプロジェクトを起動する。(コンテナで開くを押下)

4.パッケージのインストール

```bash
bun i
```

5.ローカルサーバーの起動

```bash
bun dev
```
